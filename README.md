# Energy-Efficient Hybrid STAR-RIS

This repository contains the manuscript, figures, and reproduction code in
`energy_efficient_hybrid_star_ris/`.

## Contents

- `energy_efficient_hybrid_star_ris/paper/`: LaTeX source and compiled manuscript.
- `energy_efficient_hybrid_star_ris/figs/`: EPS manuscript figures and the static system illustration.
- `energy_efficient_hybrid_star_ris/code/`: Python simulation and EPS plotting scripts.
- `energy_efficient_hybrid_star_ris/results/`: numerical summary for the manuscript figures.
- `energy_efficient_hybrid_star_ris/requirements.txt`: Python dependencies.

## Outputs

The reproduction script writes:

- `energy_efficient_hybrid_star_ris/results/hybrid_star_ris_results.json`
- `energy_efficient_hybrid_star_ris/figs/fig_pareto_boundary.eps`
- `energy_efficient_hybrid_star_ris/figs/fig_noise_sigma.eps`
- `energy_efficient_hybrid_star_ris/figs/fig_noise_update.eps`
- `energy_efficient_hybrid_star_ris/figs/fig_power_breakdown.eps`
- `energy_efficient_hybrid_star_ris/figs/fig_power_trace.eps`

The system illustration
`energy_efficient_hybrid_star_ris/figs/systemEE3_clean.jpg` is a static
manuscript asset.
