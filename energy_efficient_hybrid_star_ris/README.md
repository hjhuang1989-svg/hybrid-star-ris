# Energy-Efficient Hybrid STAR-RIS

This package contains the manuscript, figures, and reproduction code.

## Contents

- `paper/energy_efficient_hybrid_star_ris.tex`: LaTeX source.
- `paper/energy_efficient_hybrid_star_ris.pdf`: compiled manuscript.
- `figs/`: EPS manuscript figures and the static system illustration.
- `code/hybrid_star_ris_ee_se_repro.py`: reproduction script.
- `code/plot_hybrid_star_ris_eps.py`: script for drawing the manuscript EPS figures from JSON.
- `results/hybrid_star_ris_results.json`: numerical summary for the manuscript figures.
- `requirements.txt`: Python dependencies.

## Outputs

The reproduction script writes:

- `results/hybrid_star_ris_results.json`
- `figs/fig_pareto_boundary.eps`
- `figs/fig_noise_sigma.eps`
- `figs/fig_noise_update.eps`
- `figs/fig_power_breakdown.eps`
- `figs/fig_power_trace.eps`

The system illustration `figs/systemEE3_clean.jpg` is a static manuscript asset.
